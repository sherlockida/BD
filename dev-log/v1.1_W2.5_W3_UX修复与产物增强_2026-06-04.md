## W2.5: UX 修复

### 修复 1: 流式输出时能滚动了
- **根因**: `useEffect` 每收到 chunk 强制 `scrollTop = scrollHeight`
- **修复**: 添加 `isNearBottomRef` + `onScroll` 检测用户位置
  - 用户在底部 200px 内: 自动滚
  - 用户向上滚了: 不强制拉回

### 修复 2: 流式输出时输入框可用了
- **根因**: 每个 text chunk 触发一次 Zustand `set` → 整个 ChatWindow 重渲染 → textarea 感知到卡顿
- **修复**:
  1. appStore 添加 `textBuffer` — 累积 delta 到 Map<msgId, string>
  2. `requestAnimationFrame` 批量 flush（≤16ms 延迟，60fps）
  3. `MessageBubble` 包裹 `React.memo` — 未变化的已发消息不重渲染

### 修复 3: 自建 Agent 完整实现
- 前端 `/new-agent` → `createCustomAgent` 调用 `agentRegistry.createCustom()` 本地创建
- 同时 `apiCreateCustomAgent()` 调 `POST /api/agents/custom` 持久化到后端
- 用户刷新页面后自定义 Agent 仍然存在

## W3: 产物增强

### Monaco Editor 集成
- `CodeBody` 从 `<pre>` 升级为 `@monaco-editor/react` Editor
- 自动语言检测 (html/css/javascript)
- VS Dark 主题、行号、语法高亮、只读模式

### Diff Editor 升级
- Diff Tab 从自定义 DiffBody 升级为 Monaco `DiffEditor`
- Side-by-side 视图、内联差异高亮

### iframe CSP 安全沙箱
- `sandbox="allow-scripts"` (最小权限，移除 allow-same-origin)
- `injectCsp()` 注入 CSP meta 标签:
  - default-src 'self' 'unsafe-inline'
  - connect-src 'none' (阻断网络请求)
  - frame-src 'none' (阻断嵌套框架)
