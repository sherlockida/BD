## 零侵入原则遵守

- WebSocket Hook 通过 `useAgentHubWS()` 一行接入 App.tsx，不修改现有组件逻辑
- Agent DB 持久化通过 `preloadCustomAgents()` 在启动链中自然插入，不改变路由语义
- 前端 `deployArtifact` 保持相同函数签名，仅内部实现从 Mock → API
- 所有 WS 事件处理在 Store 内部消化，组件无需感知
