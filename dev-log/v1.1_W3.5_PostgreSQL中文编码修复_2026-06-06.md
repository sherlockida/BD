# v1.1 W3.5 — PostgreSQL 中文编码修复

**日期**: 2026-06-06

## 问题诊断

数据库中已有数据存在中文乱码（如 `����Ⱥ��` 替代正确中文），根因有三：

1. **docker-compose.yml**: PostgreSQL 容器未设置 locale/encoding 环境变量，`postgres:16-alpine` 默认 C locale
2. **server/src/db/index.ts**: pg Pool 未显式设置 `client_encoding = UTF8`
3. **server/src/config.ts**: 连接字符串未包含 `client_encoding` 参数

## 修复内容

### 1. docker-compose.yml
- 添加 `LANG`, `LC_ALL`, `LC_CTYPE: C.UTF-8`
- 添加 `POSTGRES_INITDB_ARGS: "--encoding=UTF-8 --locale=C.UTF-8"`
- 使用 `C.UTF-8`（Alpine musl libc 内置）而非 `zh_CN.UTF-8`（Alpine 不支持）

### 2. server/src/db/index.ts
- Pool 添加 `application_name: 'agenthub-server'` 便于调试
- 添加 `pool.on('connect')` 事件处理器，每个新连接显式 `SET client_encoding = 'UTF8'`

### 3. server/src/config.ts + .env.example
- 默认 DATABASE_URL 末尾添加 `?client_encoding=UTF8`

### 4. 数据库重建
- `docker compose down -v` 删除旧卷
- 重新启动 → `drizzle-kit push` 建表
- 清理了 7 条乱码 conversation + 关联的 messages/artifacts/versions
