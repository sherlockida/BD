# v2.1 W2.5 产物交互性升级 — Mock-First Artifact

## 背景

Agent 生成 HTML 产物时，被 `CATALOG_SYSTEM_PROMPT` 教导将不实现的功能标记为 `data-ah-placeholder`，
导致所有产物按钮点击后都是"此功能暂时还没有实现哦~"——页面"看起来完整"但"点起来空洞"。

## 核心改动

### 1. `CATALOG_SYSTEM_PROMPT` 重写 (genuiCatalog.ts:52-127)
- 理念从"占位符+拦截"扭转为 **Mock-First**：Agent 必须在生成代码中实现真实的 mock 交互
- 新增 8 种强制 mock 交互模式：Tab切换、搜索过滤、计数增减、暗色模式、表单提交、删除确认、点赞toggle、模态框
- `data-ah-placeholder` 降级为"最后手段"，仅在真正无法 mock 时使用
- 新增 `AgentHub.util` 工具文档：toast.success/error/warning/info、mockApi()、store、AgentHub.anim 动画

### 2. `AGENTHUB_RUNTIME` 增强 (ArtifactPanel.tsx:528-630)
- **多类型 Toast**: `toast.success()` / `.error()` / `.warning()` / `.info()` — 右上角彩色滑入通知
- **mockApi(delayMs, response)**: 返回 Promise 模拟 API 延迟，默认 800ms 返回 `{ok:true}`
- **store**: 简易 iframe-safe key-value 存储 (`get/set/remove/clear/keys`)
- **AgentHub.anim**: 5 种预设动画 (fadeIn, slideUp, pulse, shake, spin)
- **智能点击拦截**: 新增 `data-ah-handled="true"` 标记，Agent 自行处理的事件不再被拦截
- 保留 Error Boundary 和 `notImplemented()` 向后兼容

### 3. Mock Agent 标杆示范 (claudeCode.ts:119-340)
- `buildLandingHtml()` 完全重写：茶饮品牌 Landing Page 内置 7 种交互模式
  - 🌙 暗色模式切换 (CSS variables + data-theme)
  - 📊 Tab 三栏切换 (源头/工艺/鲜度)
  - 📋 FAQ Accordion 展开/收起
  - 📝 表单 mock 提交 (mockApi 1.2s + toast.success)
  - 🔢 统计数字递增动画 (IntersectionObserver)
  - 🎯 CTA 按钮平滑滚动 + 提示 toast
  - 🧭 导航栏 + Sticky Header

### 4. Planner Prompt 微调 (plannerService.ts:241)
- 新增规则 4.6：要求产物类任务至少包含 3 个可交互元素

## 测试结果
- Server: 2 files, 28 tests ✅
- Frontend: 13 files, 163 tests ✅
- TypeScript: 两端零编译错误 ✅

## 设计原则
- 零新依赖 —— 纯原生 JS + CSS
- 向后兼容 —— `data-ah-placeholder` / `notImplemented()` 仍生效
- Agent 自主 mock —— Runtime 提供轻量工具，交互逻辑由 Agent 生成
