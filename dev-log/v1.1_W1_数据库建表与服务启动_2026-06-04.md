## 修改背景

完成 server/ 代码后，需要实际创建数据库、建表、启动服务并验证。遇到 Docker Hub 国内无法访问的问题。

## 执行步骤

### Step 1: Docker 镜像拉取
- Docker Desktop 直连 registry-1.docker.io 超时
- 配置 daemon.json 添加国内镜像源 (`docker.m.daocloud.io`)
- 从镜像站拉取 postgres:16-alpine + redis:7-alpine
- docker tag 为标准镜像名

### Step 2: 启动容器
- docker compose up -d → PostgreSQL + Redis 运行
- 健康检查通过

### Step 3: 创建数据库表
- npx drizzle-kit push → 7 张表全部创建
- 验证: `docker exec agenthub-postgres psql -U agenthub -d agenthub -c "\dt"`
  - users, projects, conversations, messages, artifacts, artifact_versions, skills, deploys

### Step 4: 启动后端服务
- npx tsx src/index.ts → http://localhost:3001
- Health check: `{"status":"ok","db":true,"version":"1.1.0"}`
