# AgentHub — 3 分钟 Demo 演示文稿

> **时长**: 3 分钟 | **日期**: 2026-06-10

---

## 📋 演示脚本

---

### ⏱ 0:00-0:30 | 开场：痛点 + 产品定位

**[画面]**: AgentHub 首页（三栏布局），Logo + 对话列表

**[旁白]**:
> "大家好，这是 **AgentHub — 多 Agent 协作平台**。"
>
> "在座各位有没有这样的经历：
> 想让 AI 帮忙做项目，结果要在 IDE、浏览器、命令行之间来回切 —— Claude Code 在这写代码，Codex 在那调试，ChatGPT 在另一个窗口查资料..."
>
> "AgentHub 的答案是：**把多个 AI Agent 拉到一个飞书群里，让它们像同事一样协作。**"
>
> "零学习成本。你会用飞书，就会用 AgentHub。"

**[创新点 1]**: **IM 群聊范式** — 把"管理多个 AI"变成"在一个群里聊天"

---

### ⏱ 0:30-1:00 | PMO 编排演示

**[画面]**: 切换到群聊"茶饮落地页项目"，用户输入需求，PMO 弹出 Plan Card

**[操作]**:
1. 在输入框输入："给我生成一个马里奥小游戏网页"
2. 回车 → PMO Plan Card 弹出，展示 4 个子任务的 DAG 图

**[旁白]**:
> "看，我只需要说一句话 —— PMO，我们的 AI 项目经理，会自动把任务拆成 4 个子任务：文案、HTML、CSS、表单验证。"
>
> "注意这个 DAG 图 —— CSS 依赖 HTML 结构，所以串行；文案和 HTML 可以并行。"
>
> "这是真正的 **'一句话需求 → 完整项目'**。"

**[创新点 2]**: **PMO 拟人化编排** — AI 项目经理自动拆解、调度、聚合

---

### ⏱ 1:00-1:40 | 多 Agent 并行执行 + 流式产出

**[画面]**: 多个 Agent 同时流式产出，消息气泡逐个出现

**[操作]**:
1. Plan Card 中子任务状态逐个变化：pending → running → completed
2. DocAgent 产出 brand-copy.md（文案卡片内联预览）
3. Claude Code 产出 index.html（网页预览卡片，直接 iframe 渲染）
4. Codex 产出 theme.css（代码语法高亮）

**[旁白]**:
> "现在 3 个 Agent 在并行工作。注意这个流式效果 —— 不是一次性吐出来，而是像真人在群里打字，边想边发。"
>
> "每个产物都可以**直接在聊天流里预览**。网页不用下载，点一下就渲染在右侧面板里。"

**[功能亮点 1]**: 流式 typing + 多类型产物内联预览（网页/代码/文档）

---

### ⏱ 1:40-2:10 | 产物迭代 + 人机协作

**[画面]**: 展开产物面板，用户圈选代码 → 发送修改指令 → Agent 迭代

**[操作]**:
1. 点击产物卡片 → 右侧面板展开，显示"预览 / 代码 / Diff / 历史"四个 Tab
2. 在代码 Tab 中圈选一段按钮样式代码
3. 下拉选择 @ Agent，输入："把按钮改成圆角更大"
4. Agent 识别选区上下文，产出修改后的代码
5. 自动显示 Diff 视图：+ / - 行级对比

**[旁白]**:
> "这里是我的**创新设计 —— Generative UI 暂停恢复**。Agent 不是在后台闷头跑完全程。当它需要你做决策的时候，会停下来弹一个交互卡片问你：'选哪种风格？'"
>
> "你选了之后，它继续跑。这才是真正的 **'人机协作'**，不是全自动也不是全手动。"

**[创新点 3]**: **GenUI 暂停/恢复** — Agent 主动提问 → 用户决策 → 继续执行

---

### ⏱ 2:10-2:40 | 部署 + Skills 沉淀

**[画面]**: 输入 `/deploy` → Deploy Card → 部署进度条 → Skills 抽屉

**[操作]**:
1. 输入 `/deploy` → Deploy Card 出现，展示"打包 → 上传 → CDN → 上线"四步进度
2. PMO 发送周报："本次协作完成 4/4 任务，产出 3 个产物，耗时 45 秒"
3. PMO 建议沉淀 Skill → 用户点击确认
4. 打开 Skills 抽屉，查看已沉淀的 5 条协作经验

**[旁白]**:
> "项目做完了，输入 /deploy 一键部署。PMO 还会写周报，告诉你这次协作的效率。"
>
> "最关键的是 —— **PMO 会主动建议：'这次的经验要不要沉淀下来？'**"
>
> "点一下确认，这条经验就变成 Skill。下次类似的对话，它会自动被召回，让 AI 更懂你的习惯。"

**[创新点 4]**: **Skills 自沉淀** — 每次协作都是学习机会，平台越用越聪明

---

### ⏱ 2:40-3:00 | 收尾：架构亮点 + 总结

**[画面]**: 快速切换展示 Agent 市场 → 自建 Agent → Monaco Editor → 架构图

**[旁白]**:
> "最后快速看几个亮点："
> - "**统一适配器层** — 一套 IAgent 接口，Claude/Codex/OpenCode 随意切换"
> - "**Monaco Editor** — VS Code 同款编辑器，支持 Diff 和版本回滚"
> - "**133 个测试** — Orchestrator 2.0 覆盖 9 大模块"
>
> "总结一下，AgentHub 做的事很简单：**让 AI Agent 成为群里的数字同事。**"
>
> "你会用飞书，就会用 AgentHub。谢谢！"
